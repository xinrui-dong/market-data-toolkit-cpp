## 复现 / Reproduce

安装 C++17 编译器、CMake ≥ 3.24、构建工具、Doxygen 和 Python ≥ 3.9，然后执行：
With a C++17 compiler, CMake ≥ 3.24, a build tool, Doxygen and Python ≥ 3.9 installed:

~~~sh
git clone --branch v0.3.2 --depth 1 https://github.com/xinrui-dong/market-data-toolkit-cpp.git
cd market-data-toolkit-cpp
bash scripts/verify.sh
./build/bin/market_data --input data/sample_prices.csv --window 3 --output build/analysis.csv
~~~

合成样例价格 / Synthetic prices: `[100, 110, 99, 108]`。收益率 / returns: empty, `0.1`, `-0.1`, `1/11`；SMA(3): empty, empty, `103`, `317/3`。浮点输出允许舍入差异 / floating-point output may show rounding.

完整流程 / Verification sequence: **configure → build → 31 tests → benchmark + JSON validation → Doxygen + link validation**。生成文件 / Outputs: `build/analysis.csv`, `build/benchmark.json`, `build/docs/html/index.html`。测速使用合成输入；Release 中的 CI 测量与 [本机性能报告](benchmark-results.md)分开标注 / CI measurements and local measurements are identified separately.
